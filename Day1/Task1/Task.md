### Practical Work

Created a practical HTML/CSS project to observe:

1. Block vs inline behavior
2. Different display properties
3. Padding behavior
4. Margin behavior
5. Different CSS units
6. Responsive behavior using viewport units

### What I Observed

- Block elements start on a new line.
- Inline elements remain in the same line.
- inline-block allows width and height while participating in inline flow.
- display: none removes the element from the layout.
- Padding creates space inside the border.
- Margin creates space outside the border.
- vw changes according to viewport width.
- vh changes according to viewport height.
- px does not scale with viewport size in the same way viewport-relative units do.
- rem is based on the root font size.
- em depends on the relevant element font size.
